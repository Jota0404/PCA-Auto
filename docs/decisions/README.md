# Architecture Decision Records

Esta pasta contém decisões arquiteturais que podem afetar significativamente o rumo do PCA-Auto.

## Regra

Não criar ADR para toda decisão pequena.

Registrar formalmente quando a decisão:

- altera uma fronteira arquitetural;
- cria uma dependência relevante;
- seria cara de reverter;
- precisa ficar clara para futuros desenvolvedores.
